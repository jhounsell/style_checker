# Content checker for the Home Office

This tool is a set of rules hosted inside GOV.UK prototype kit, run using javascript. It allows content authors working in the Home Office to check content from anywhere against:
* the [Home Office design system content style guide](https://design.homeoffice.gov.uk/content-style-guide)
* GOV.UK readability recommendations
* the [Automated Readability Index formula](https://readable.com/readability/automated-readability-index/)

We're looking to add more features in the future.

For more detail see [the tool's limitations](app/views/limitations.html).
Or see guidance on how the tool works on the [homepage](app/views/index.html).
